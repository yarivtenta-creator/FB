SECTION 1 — WHAT PROJECT 770 IS
================================================================================

Name:    PROJECT 770 — AI Marketing Growth Operating System
Short:   pkg770
Type:    Node.js application (pure Node, zero npm dependencies)
Port:    6500
Entry:   server.js
Source:  Google Drive folder ID: 1j9Vtqs0wWjXmOVRgiqYZW8DrRdKUqEW-
Repo:    yarivtenta-creator/FB (GitHub)

The system is a modular AI marketing OS with:
- 535+ intelligence modules (pure computation, offline, no API keys)
- A client intake system (questionnaire → CRM)
- A creative intelligence workflow engine
- A CRM with leads, clients, opportunities, discovery, communications
- A dashboard UI (dashboard/index.html, served at port 6500)
- A module runner that auto-discovers and executes any .js file placed in
  intelligence_modules/

Technology decisions:
- No external API calls by default (offline-capable)
- No secrets stored in plain text
- All modules are pure computation (deterministic, testable)
- JSON for all data storage
- Static HTML dashboard served directly by Node's http module

1. intelligence_modules/viroscope_claude_video_router.js  [NEW]
   ─────────────────────────────────────────────────────
   Module name:   Viroscope Claude Video Router
   Client name:   Viral Video Builder
   Module ID:     viroscope_claude_video_router
   Pattern:       Follows viral_intelligence.js exactly
   Exports:       { assess, generateNiches, generateClaudePrompt,
                    generateExport, saveProject, STATUS }

   PURPOSE:
   Workflow bridge between client intake and video production tools.
   Intake → ViroScope niche → ViroScope results → Claude production prompt
   → Claude result pasted back → destination-specific export prompt.
   Manual copy/paste only. No API calls. No external dependencies.

   4 STAGES (called via input.stage):

   STAGE 1: generate_niches
     Input:  intake data (company, industry, offer, audience, platform, language)
     Output: 5 ViroScope niche options (max 60 chars each), recommended first
     Logic:  Derives angles from intake — direct offer+audience, how-to,
             results/transformation, industry authority, platform-specific
     Example niches:
       "online personal training for busy professionals"
       "how to grow with online personal training"
       "fitness coaching content that goes viral"

   STAGE 2: generate_claude_prompt
     Input:  intake data + selected_viroscope_niche + raw_viroscope_results
             + platform + language + production_style + content_goal
     Output: Full Claude production prompt (ready to paste into claude.ai)
     Prompt asks Claude to:
       a) Pick best viral idea from ViroScope results
       b) Explain WHY it fits the client
       c) Produce full video production package:
          - Video concept (hook angle, message, emotional driver)
          - Hook (exact first 3 seconds)
          - Script outline (intro/content/CTA)
          - Scene breakdown (3-6 scenes with visuals, text, voiceover)
          - Production style notes (camera, pacing, music, colour)
          - Caption/overlay copy
          - Call to action (exact wording)
          - Platform optimisation specs
     Originality rule enforced: no competitor copying, only structure/psychology

   STAGE 3: generate_export
     Input:  pasted_claude_result + selected_destination + intake data
     Output: Destination-specific export prompt

     8 DESTINATIONS:
     higgsfield         → cinematic prompt + params (AR, duration, style,
                          negative prompt, motion notes)
     gemini             → structured video generation prompt with scene list
     claude             → 3 refinement prompts (script punch-up, production
                          audit, hook variation generator)
     runway             → Runway ML text-to-video / image-to-video prompt
     veo                → Veo parameters (resolution, frame rate, audio)
     kling              → Kling AI professional mode prompt
     editor_brief       → Full human editor brief: shot list, voiceover,
                          timeline (hook 0-3s, value, CTA), captions,
                          B-roll rules, music direction, export specs
                          per platform (TikTok, Reels, YouTube, LinkedIn)
     youtube_upload_package → Title options (3 variants), description
                          template (SEO), tags, thumbnail prompt for AI/
                          designer, pinned comment, chapters template

   STAGE 4: save_project
     Input:  all accumulated data from stages 1-3
     Output: Project object with all fields:
       { project_id, intake_id, client_name,
         viroscope_niche_options[], selected_viroscope_niche,
         raw_viroscope_results, generated_claude_prompt,
         pasted_claude_result, selected_destination,
         exported_prompt, created_at, updated_at }
