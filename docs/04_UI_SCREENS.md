# UI Screens

## Dashboard
- KPI cards: total leads, leads by status, drafts pending approval
- Recent activity feed
- Quick-add lead button

## Leads List
- Filterable table (status, niche, country)
- Search bar
- Add Lead button
- CSV Import / Export buttons
- Click row → Lead Detail

## Lead Detail
- Full lead info display and edit form
- Profile section (AI analysis results)
- Content items list
- Outreach drafts list
- Activity timeline
- AdsPower browser profile section

## Content Analysis
- Paste text area for website/social content
- Screenshot upload
- Run Analysis button
- Results display with opportunities and pain points

## Outreach Drafts
- Generate draft form (channel, tone selectors)
- Display all drafts for lead
- Edit inline
- Send to Approval button

## Approval Queue
- List of pending drafts
- Each item: lead name, channel, tone, draft preview
- Approve / Reject / Edit buttons
- Compliance fields (opt-out, DNC, lawful basis)
- Next action field

## AdsPower Settings
- Connection test button
- Status indicator (connected/disconnected)
- API key field
- Base URL field
- Enable/Disable toggle

## Export
- Select leads by filter or manually
- Export to CSV
- Export selected drafts to CSV
