## 4. איך באמת מריצים משימות במקביל ב-Claude Code (הנושא שנסגר בסוף)

הסשן הראשי רץ בטור, אבל הוא יכול **להשיק כמה subagents בבת אחת** (מספר קריאות Task בצעד אחד).
- כל subagent = הקשר מבודד, בלי קשר לאחרים חוץ מהטקסט שנמסר לו.
- אפשר לצמד כל subagent למודל זול/חזק: **Haiku** = טקסט פשוט, **Sonnet** = בנייה/עיצוב/קוד, **Opus** = חשיבה כבדה.
- מגבלות: ~10–16 רצים בו־זמנית (השאר בתור); כל subagent מחזיר רק את ההודעה הסופית שלו.

### שתי גישות שהוצעו

**גישה A — Flat parallel:** פרומפט אחד → 10 משימות עצמאיות במקביל, כל אחת עם רמז מודל.
מתאים כשכל משימה היא מיומנות בודדת (מייל, עריכת תמונה, סיכום).

**גישה B — Parallel + sub-agents:** כל משימה כבדה מתפצלת לתפקידים (build / design / copy / QA) שגם רצים במקביל, ואז MERGE אחד מאחד לכל משימה.
מתאים למשימות כבדות (landing page, חנות Shopify).

**המלצה:** ברירת מחדל Haiku לכל דבר, שדרוג ל-Sonnet רק לבנייה/עיצוב/קוד, Opus רק לארכיטקטורה. אפשר לערבב — משימות פשוטות נשארות flat, כבדות מקבלות תפקידים. הוצע ליצור פקודה קבועה `/parallel-missions`.
