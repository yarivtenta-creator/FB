# Vision

GPT SAAS is a private project operating system.
Focus on finishing projects, not accumulating chats.

The system is the shared source of truth for Claude, ChatGPT, Higgsfield, and future
co-workers. Scattered chats are replaced by structured project folders, Markdown state files,
handoff files, a registry, a dashboard, a recovery workflow, and a finish-project workflow.

The state lives in files, not in chat.
